# SurgHistory (v0.2-Surg) 🏥⚡

**سامانه پیشرونده و ۱۰۰٪ آفلاین (Offline-First PWA) برای ثبت شرح‌حال، معاینه فیزیکی، پاراکلینیک و استدلال بالینی در بخش جراحی عمومی**

طراحی‌شده ویژه دانشجویان پزشکی، کارورزان (اینترن‌ها) و رزیدنت‌های جراحی در بیمارستان‌های آموزشی با ارگونومی بالا برای تبلت (Split-Screen) و موبایل (Thumb-Zone).

---

## ✨ ویژگی‌های کلیدی (Key Features)

- **۱۰۰٪ آفلاین (Offline-First PWA):** کارکرد بدون قطعی در نقاط کور بیمارستان با کشینگ Service Worker (`sw.js`) و قابلیت نصب روی گوشی و تبلت (Add to Home Screen).
- **الگوی تگ‌های لمسی ۳ حالته (Tri-State Clinical Chips):**
  - حالت `0`: خنثی / پرسیده‌نشده
  - حالت `+1`: مثبت کلیدی (Present / Pertinent Positive) به همراه باز شدن **کادر توضیحات درجا (Inline Contextual Input)**
  - حالت `-1`: رد هدفمند و منفی کلیدی (Pertinent Negative)
- **نقشه فضایی-زمانی درد در HPI (Pain Spatial-Temporal Trajectory Mapper):**
  - پوشش الگوهای موضعی، ژنرالیزه، ارجحیتی و الگوی مهاجر جراحی (Shifting Pain) با ثبت تفکیک‌شده نواحی آغازین و ثانویه.
  - ثبت چندانتخابی محل‌های انتشار درد (Radiation).
- **لاگ کمبودهای سیستم (System Gap Logger):**
  - امکان ثبت فوری گزینه‌های خارج از لیست در انتهای هر بخش جهت درج در متن پرونده و ذخیره‌سازی در تله‌متری برای ارتقای مستمر نرم‌افزار.
- **سوابق ۳ حالته پزشکی (Tri-State PMH):**
  - تفکیک خودکار بیماری‌های مثبت (با جزئیات درجا) از منفی‌های کلیدی.
- **بررسی کامل ۱۱ سیستم بدن در ROS:**
  - مطابق بالاترین استانداردهای آموزشی پزشکی.
- **پاراکلینیک هوشمند و هشدار مقادیر بحرانی:**
  - ارزیابی لحظه‌ای CBC، آنزیم‌های کبدی، الکترولیت‌ها، تومورمارکرها و علائم اختصاصی سونوگرافی و سی‌تی اسکن با برچسب‌های `↑ High` و `↓ Low`.
- **موتور تله‌متری ضدِ فراموشی (Clinical Telemetry Engine):**
  - مجهز به واچ‌داگ ۱۵ ثانیه‌ای جهت محاسبه زمان واقعی راند بالینی و پیشگیری از ثبت زمان‌های غیرواقعی.
- **صندوق آفلاین پرونده‌های شیفت (Offline Shift Vault):**
  - ذخیره‌سازی محلی چندین پرونده در طول شیفت و امکان دانلود تجمیعی همه پرونده‌ها در قالب فایل JSON استاندارد.

## 🚀 نحوه اجرا (Local Run)

این سامانه به صورت ماژولار با جاوااسکریپت استاندارد (Vanilla ES Modules) و بدون نیاز به پکیج‌های بیلد سنگین پیاده‌سازی شده است:

```bash
# با استفاده از پایتون
python -m http.server 8080

# یا با استفاده از Node / npx
npx serve -l 8080
```
سپس مرورگر خود را در آدرس `http://localhost:8080` باز کنید.

## 📂 ساختار فایل‌ها (Architecture)

```text
├── index.html          # ساختار اصلی رابط کاربری
├── manifest.json       # مانیفست وب‌اپلیکیشن جهت نصب PWA
├── sw.js               # سرویس ورکر برای کشینگ و کارکرد آفلاین
├── css/
│   └── clinical-ui.css # سیستم طراحی مدرن Dark/Light
├── js/
│   ├── schema.js       # اسکیما و دیکشنری جامع بالینی ۱۲ بخشی
│   ├── telemetry.js    # موتور زمان‌سنجی هوشمند و لاگ کمبودها
│   ├── generator.js    # تولیدکننده قطعی و استاندارد متن شرح‌حال
│   └── app.js          # مدیریت وضعیت، رندرهای پویا و حافظه محلی
└── icons/              # آیکون‌های وکتور SVG اختصاصی PWA
```
